# 交接文档：上传本地数据库覆盖线上（方案一）

**目标**：用本地带解析的题库数据库覆盖线上数据库，使线上做题也能显示解析。

**执行方**：由另一 Agent 或运维按本文档步骤执行。

---

## 一、前置条件（请先确认）

1. **本地已生成压缩包**  
   文件路径：`lnexam/server/data/lnexam-production.db.gz`  
   若不存在，在项目根目录执行：  
   `cd server && node scripts/export-db-for-production.js`

2. **已拿到线上环境信息**（由项目负责人提供）  
   - 服务器地址：`[SERVER]`（IP 或域名）  
   - SSH 登录用户：`[USER]`  
   - 线上项目根目录或数据目录：`[REMOTE_DATA_DIR]`（例如 `/app/server/data` 或 `/home/xxx/lnexam/server/data`）  
   - 当前服务如何停止/启动：`[STOP_CMD]` / `[START_CMD]`（例如 Docker 容器名、systemd 服务名、或进程说明）

---

## 二、执行步骤（按顺序）

### 步骤 1：上传压缩包到服务器

在**本地项目根目录**（即包含 `server`、`documents` 的目录）执行：

```bash
scp server/data/lnexam-production.db.gz [USER]@[SERVER]:/tmp/lnexam-production.db.gz
```

- 将 `[USER]`、`[SERVER]` 替换为实际值。  
- 若使用 SSH 密钥且需指定：  
  `scp -i /path/to/key server/data/lnexam-production.db.gz [USER]@[SERVER]:/tmp/lnexam-production.db.gz`  
- 提示输入密码时输入 SSH 密码。

### 步骤 2：登录服务器

```bash
ssh [USER]@[SERVER]
```

### 步骤 3：在服务器上停止服务

按实际部署方式执行其一（由项目负责人确认）：

- **Docker**：  
  `docker stop [容器名]`  
  （容器名可用 `docker ps` 查看）
- **systemd**：  
  `sudo systemctl stop [服务名]`
- **PM2**：  
  `pm2 stop [应用名]`
- **直接 Node 进程**：  
  找到占用 3030 端口的进程并 kill（例如 `lsof -i :3030` 后 `kill <PID>`）

### 步骤 4：备份当前线上数据库（可选但建议）

```bash
cp [REMOTE_DATA_DIR]/lnexam.db [REMOTE_DATA_DIR]/lnexam.db.bak.$(date +%Y%m%d-%H%M%S)
```

将 `[REMOTE_DATA_DIR]` 替换为实际的线上数据目录。

### 步骤 5：解压并覆盖线上数据库

```bash
gunzip -c /tmp/lnexam-production.db.gz > [REMOTE_DATA_DIR]/lnexam.db
```

再次将 `[REMOTE_DATA_DIR]` 替换为实际路径。

### 步骤 6：启动服务

按实际部署方式执行其一：

- **Docker**：  
  `docker start [容器名]`
- **systemd**：  
  `sudo systemctl start [服务名]`
- **PM2**：  
  `pm2 start [应用名]`
- **直接 Node**：  
  进入项目目录后执行 `node server/server.js` 或项目约定的启动命令。

### 步骤 7：清理临时文件（可选）

```bash
rm /tmp/lnexam-production.db.gz
```

---

## 三、验证

1. 浏览器打开线上站点，进入任意题目（练习或模拟考试）。  
2. 作答后进入「查看解析」或答案解析区域。  
3. 确认是否出现解析文案（非「暂无解析」）。

若仍无解析，检查：  
- 线上 `[REMOTE_DATA_DIR]/lnexam.db` 是否为新覆盖的文件（可看修改时间）。  
- 服务是否已用新进程/新容器启动（无旧进程仍读旧库）。

---

## 四、回滚（若覆盖后出现问题）

在服务器上执行（将备份文件名改为实际生成的）：

```bash
cp [REMOTE_DATA_DIR]/lnexam.db.bak.YYYYMMDD-HHMMSS [REMOTE_DATA_DIR]/lnexam.db
```

然后按上述方式**重启服务**。

---

## 五、占位符汇总（执行前由负责人填好）

| 占位符 | 说明 | 示例 |
|--------|------|------|
| `[SERVER]` | 服务器 IP 或域名 | `123.45.67.89` 或 `exam.example.com` |
| `[USER]` | SSH 登录用户名 | `root`、`ubuntu`、`deploy` |
| `[REMOTE_DATA_DIR]` | 线上 lnexam.db 所在目录 | `/app/server/data` |
| `[STOP_CMD]` / `[START_CMD]` | 停服/启服命令或方式 | 见步骤 3、6 |
