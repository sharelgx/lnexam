# 中小学在线做题网站 · 产品需求文档（PRD）

> 本文档基于现有在线备考项目抽象而成，面向**中小学做题网站**产品形态，强调功能与多端适配，不约束具体布局与视觉模板。

---

## 一、产品概述

### 1.1 产品定位

面向**中小学（K12）**的在线做题与备考平台。学生可登录后按科目/知识点练习、参加模拟考试，系统记录答题与错题，并支持学习报告与会员能力扩展。管理员可管理用户、题库分类与考试配置。

### 1.2 目标用户

| 角色     | 说明 |
|----------|------|
| 学生/考生 | 使用账号登录，进行练习、模拟考试，查看错题与学习报告 |
| 管理员   | 管理用户、设置会员、维护科目/知识点分类与考试配置 |

### 1.3 多终端适配要求

- **适配终端**：PC 端、平板、手机等各类终端，保证核心流程在各终端可用。
- **实现方式**：不限定布局模板，可采用响应式布局、独立移动端页面或自适应设计，由实现方根据业务选择。
- **核心原则**：登录、做题、考试、查看结果、错题本、学习报告等核心功能在主流终端上均可完成，交互符合该终端习惯（如触控友好、关键操作易达）。

## 二、功能模块总览

```
┌─────────────────────────────────────────────────────────────────┐
│  未登录：登录 / 注册 → 进入主端                                   │
├─────────────────────────────────────────────────────────────────┤
│  主端：学习中心 | 知识点复习 | 模拟考试 | 专项练习 | 错题本 |     │
│        学习报告 | 会员中心 | [管理员] 后台管理                     │
├─────────────────────────────────────────────────────────────────┤
│  答题流程：选择练习/考试 → 答题界面（计时、题号导航、交卷）→ 结果页 │
└─────────────────────────────────────────────────────────────────┘
```

## 三、功能需求详述

### 3.1 认证与账号

| 功能点 | 描述 | 约束说明 |
|--------|------|----------|
| 登录   | 支持账号+密码登录；登录成功后进入主端，并可持续访问需登录能力。 | 不限定账号类型（可为手机号、学号、用户名等，由业务配置）。 |
| 注册   | 支持新用户注册，需校验必填项与格式（如姓名长度、手机号格式、密码长度、确认密码一致）。 | 不约束注册项数量与字段名，可扩展（如年级、学校等）。 |
| 登出   | 用户主动登出后清除登录态，回到登录/首页。 | - |
| 登录态 | 采用服务端可校验的登录态（如 JWT），前端在需要时携带。 | 不限定具体技术实现。 |

**抽象说明**：认证模块提供「谁在使用」的识别能力，为后续学习数据、错题、考试记录按用户隔离提供基础。

---

### 3.2 主端框架与导航

| 功能点 | 描述 | 约束说明 |
|--------|------|----------|
| 主端入口 | 登录后进入的主界面，承载各功能入口与当前用户信息展示。 | 不约束为单栏/多栏、是否侧边栏、是否底部 Tab，由实现方按多端适配需要设计。 |
| 导航结构 | 至少包含：学习中心（首页/仪表盘）、知识点复习、模拟考试、专项练习、错题本、学习报告、会员中心；管理员角色额外可见「后台管理」入口。 | 不约束菜单层级、图标、文案措辞，可随学段（小学/初中/高中）定制。 |
| 用户信息展示 | 在主端可见当前用户称呼、角色/身份标签、会员状态（如免费/VIP 及到期时间）。 | 不约束展示位置与样式。 |

**多端说明**：小屏下导航可收折为抽屉、底部导航、折叠菜单等，保证各核心入口可访问即可。

---

### 3.3 学习中心（首页/仪表盘）

| 功能点 | 描述 | 约束说明 |
|--------|------|----------|
| 汇总统计 | 展示当前用户的学习汇总：总答题数、总正确率（或正确题数/总题数）、参加考试次数、错题数量。 | 不约束卡片数量、排版与图表形式。 |
| 科目进度 | 按科目（如数学、语文等）展示「掌握度」或答题进度（如正确率/已练题数）。 | 科目种类与名称可配置，不限定为固定三科。 |
| 近期考试 | 展示最近若干次模拟考试记录（考试名称、日期、题量、得分或等级）。 | 条数可配置，不约束展示样式。 |
| 倒计时/目标 | 可选展示与目标考试日期或目标的倒计时、激励文案。 | 非必须，若存在则需支持配置或关闭。 |

**抽象说明**：学习中心提供「一眼看清学习概况」的能力，具体指标与展示方式可按学段与运营需求调整。

---

### 3.4 知识点与分类体系

| 功能点 | 描述 | 约束说明 |
|--------|------|----------|
| 分类层级 | 支持多级分类：一级一般为科目（如数学、语文），二级/三级为知识点或章节。题目可关联到某一级分类。 | 层级深度与命名由业务决定，不限定为 2 级或 3 级。 |
| 按科目浏览 | 用户可按科目查看该科目下的知识点列表，并进入「按知识点做题」。 | 不约束为网格、列表或树形，适配多端即可。 |
| 按知识点选题 | 选择某一知识点后，可加载该知识点下的题目进行练习；练习时即时反馈对错并展示解析。 | 题目来源为题库中关联到该分类的题目，不约束题量上限。 |

**抽象说明**：分类体系是「练什么」的基础，与题库、考试配置共用同一套分类数据，便于扩展新科目与知识点。

---

### 3.5 专项练习

| 功能点 | 描述 | 约束说明 |
|--------|------|----------|
| 练习配置 | 用户可配置：科目（单科/多科/全科）、题目数量、练习模式（如整卷计时作答 / 逐题即时反馈）。 | 不约束表单项的布局与默认值。 |
| 组卷与作答 | 按配置从题库抽题（可随机或按规则），进入统一答题界面；支持上一题/下一题、题号导航、可选计时。 | 与「模拟考试」共用同一套答题与交卷逻辑时，可通过参数区分是否计入正式考试记录。 |
| 即时反馈模式 | 若为「逐题即时反馈」模式，选答后立即显示对错与解析，并可选记录错题、更新统计。 | 不约束解析展示样式。 |

**抽象说明**：专项练习强调「自选范围与题量」的练习方式，与「按知识点练习」互补，均可复用同一答题组件与统计逻辑。

---

### 3.6 模拟考试

| 功能点 | 描述 | 约束说明 |
|--------|------|----------|
| 考试配置列表 | 展示可参加的模拟考试列表；每项包含：名称、说明、题量、限时（分钟）、可选标签（如「完整版」「全科」等）。 | 列表来源由后端或配置提供，不约束条数与展示样式。 |
| 开始考试 | 用户选择某场考试后，系统按配置从题库组卷（按科目/知识点等规则），进入答题界面并开始计时。 | 组卷规则由后端或配置决定（如按科目比例、随机抽题等）。 |
| 答题过程 | 与专项练习共用能力：题号导航、上一题/下一题、已答/未答状态、倒计时显示；时间到可自动交卷。 | 不约束题号区布局（如底部横条、侧边栏、弹层等）。 |
| 交卷与确认 | 支持用户主动交卷；若有未答题可二次确认。交卷后进入结果页。 | - |
| 考试记录 | 每次交卷后记录：考试标识、得分（或正确题数/总题数）、用时、答题明细（可选），并写入该用户的历史记录。 | 记录用于学习中心「近期考试」与学习报告，不约束存储结构。 |

**抽象说明**：模拟考试是「限时、成套、有记录」的做题形态，与专项练习在交互上可高度一致，差异主要在配置与是否写入考试记录。

---

### 3.7 答题与结果页

| 功能点 | 描述 | 约束说明 |
|--------|------|----------|
| 题目展示 | 题干、选项（如 A/B/C/D）清晰可读；选项可点击选择，已选状态可区分。 | 不约束单选/多选题型扩展，当前以单选为例。 |
| 题号导航 | 可快速跳转到指定题号；已答/未答/当前题可有视觉区分。 | 多端下可折叠或简化，保证跳转可用即可。 |
| 计时 | 若该次练习/考试有时限，展示剩余时间；时间到可自动交卷。 | 不约束显示位置与样式。 |
| 结果页 | 交卷后展示：总分或正确率、等级或评语、正确/错误/未答数量；可选展示逐题详情（对错、正确答案、解析）。 | 不约束版式与是否分步展示（如先总分再详情）。 |
| 结果后操作 | 支持「返回学习中心/模拟考试列表」「查看错题解析」「再考一次」等，按业务提供即可。 | - |

**多端说明**：答题区与题号区在小屏上可采用上下结构或可折叠区域，保证答题、翻题、交卷流程顺畅。

---

### 3.8 错题本

| 功能点 | 描述 | 约束说明 |
|--------|------|----------|
| 错题收集 | 在练习或考试中答错的题目，可自动加入当前用户的错题列表（去重）。 | 可配置是否在「即时反馈」练习中也记错题。 |
| 错题列表 | 按用户展示其错题列表；支持按科目筛选；可展示题目摘要或数量。 | 不约束为列表、卡片或分组展示。 |
| 错题练习 | 支持将当前筛选的错题作为一套练习进入答题流程（可带即时反馈），作答后可根据结果更新错题本（如做对可移除）。 | 移除规则可配置或后续迭代。 |
| 错题同步 | 错题列表支持与服务端同步，便于多端一致与长期保存。 | - |

**抽象说明**：错题本是「针对薄弱点反复练」的能力，与知识点练习、专项练习形成闭环。

---

### 3.9 学习报告

| 功能点 | 描述 | 约束说明 |
|--------|------|----------|
| 整体统计 | 总答题数、总正确率、各科目掌握度（或正确率）。 | 与学习中心可复用数据，展示维度可更细。 |
| 薄弱知识点 | 按知识点（或分类）统计正确率，展示正确率较低或答题量较多的知识点，便于用户针对性练习。 | 不约束排序规则与展示条数。 |
| 学习活动 | 可选展示近期答题/考试活跃情况（如按日、周）。 | 非必须，若存在可不约束图表形式。 |

**抽象说明**：学习报告为「学得怎么样」提供结构化反馈，不约束图表与排版，便于按学段扩展。

---

### 3.10 会员中心

| 功能点 | 描述 | 约束说明 |
|--------|------|----------|
| 状态展示 | 展示当前为免费用户或 VIP 会员；若为会员则展示到期时间。 | 不约束是否展示权益对比、升级入口等，由运营需求决定。 |
| 权益扩展 | 会员能力可由业务扩展（如更多考试、专属题目、去广告等），不在本 PRD 中限定。 | - |

**抽象说明**：会员模块提供「身份与权益」的展示与扩展点，与后台「设置 VIP」配合使用。

---

### 3.11 后台管理（管理员）

| 功能点 | 描述 | 约束说明 |
|--------|------|----------|
| 权限 | 仅管理员角色可访问后台；主端导航中仅对管理员显示入口。 | - |
| 用户管理 | 用户列表（账号、姓名、角色、会员状态、到期时间等）；支持将用户设为 VIP 或取消 VIP，并设置/清空到期时间。 | 不约束列表样式与筛选条件。 |
| 数据概览 | 可选展示：用户总数、考试总场次、VIP 用户数等，便于运营查看。 | 非必须，指标可增删。 |
| 分类管理 | 对「科目—知识点」层级结构进行增删改：新增/编辑/删除分类，设置父级、名称、层级、排序、与科目的关联等。 | 与题库、考试配置共用分类数据，不约束为树形或表单。 |
| 考试配置 | 若考试列表来自后台配置，则需支持对模拟考试的增删改（名称、科目范围、题量、限时、说明、排序等）。 | 若考试由运营固定配置则可不做后台界面，仅需数据来源一致。 |

**抽象说明**：后台管理面向运营与内容维护，保证用户、分类、考试配置可维护即可，不约束为单页还是多页、表格还是卡片。

## 四、数据与接口抽象

### 4.1 核心实体（概念层）

| 实体 | 说明 |
|------|------|
| 用户 | 账号、登录态、角色（如学生、管理员）、会员类型与到期时间、姓名等资料。 |
| 科目/分类 | 多级分类，用于组织知识点并与题目、考试配置关联。 |
| 题目 | 题干、选项、正确答案、解析、所属科目与分类；题目 ID 唯一。 |
| 练习/考试配置 | 名称、涉及科目、题量、限时、说明等，用于组卷与展示列表。 |
| 用户统计 | 总答题数、总正确数、考试次数、各维度（如按科目/知识点）的答题与正确数。 |
| 错题 | 用户与题目 ID 的关联，支持列表拉取与同步。 |
| 考试记录 | 用户、考试标识、得分、总题数、用时、答题明细（可选）、时间。 |

### 4.2 接口能力（不限定路径与协议）

- **认证**：登录、注册、登出；获取当前用户信息。
- **用户数据**：获取/更新当前用户的学习统计；获取/更新当前用户错题 ID 列表；获取考试历史；提交单次考试记录。
- **内容**：获取分类树（科目—知识点）；按科目或分类获取题目列表；按题目 ID 获取单题详情。
- **配置**：获取模拟考试配置列表（用于前端展示与组卷）。
- **管理端**：用户列表与会员设置；分类的增删改；可选：考试配置的增删改、数据概览。

具体 REST 路径、请求体、状态码由实现方定义，本 PRD 只要求上述能力具备且与前端约定一致。

## 五、非功能需求（摘要）

| 维度 | 要求 |
|------|------|
| 多端适配 | 核心流程在 PC、平板、手机上均可完成；布局与交互方式不限定，由实现方选择。 |
| 性能 | 题目列表、单题加载、交卷等关键操作响应合理，避免长时间白屏。 |
| 安全 | 登录态校验、接口鉴权、敏感操作（如设置 VIP）仅管理员可执行。 |
| 可维护性 | 科目、知识点、考试配置可通过后台或配置变更，便于扩展学段与学科。 |

## 六、版本与迭代建议

- **V1（MVP）**：登录/注册、学习中心、按知识点练习、模拟考试（固定若干套）、错题本、学习报告、会员展示、管理员用户与分类管理。
- **后续**：专项练习参数化、错题本「做对移除」、考试配置后台化、多题型（多选、填空等）、学习报告图表与维度扩展、多端独立优化等。

## 七、文档说明

- 本文档为**产品需求说明**，抽象为「中小学做题网站」形态，不绑定具体学校或考试名称。
- **不约束**：页面布局、组件模板、视觉风格、技术栈、接口 URL 与报文格式。
- **强调**：功能完整、多终端可用、分类与考试可配置可扩展。
- 实际实施时可根据目标学段（小学/初中/高中）与运营需求，在本文档基础上做文案、字段与展示上的定制。
