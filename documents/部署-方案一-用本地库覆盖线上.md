# 方案一：用本地数据库覆盖线上（带解析与完整题库）

使线上与本地使用同一份数据库，做题即可看到解析。

---

## 一、本地：导出数据库压缩包

在项目里执行（无需停本地服务）：

```bash
cd server
node scripts/export-db-for-production.js
```

会生成 **server/data/lnexam-production.db.gz**（约一百多 KB），即当前本地库的压缩包。

---

## 二、上传到服务器

用 scp、SFTP 或云控制台「文件上传」，把 **lnexam-production.db.gz** 传到服务器任意目录（例如 `/tmp` 或项目旁的 `upload`）。

示例（scp）：

```bash
scp server/data/lnexam-production.db.gz 用户@服务器IP:/tmp/
```

---

## 三、在服务器上替换并重启

1. **停止当前服务**（按你实际方式，例如）  
   - Docker: `docker stop <容器名>`  
   - systemd: `sudo systemctl stop lnexam`  
   - 或直接结束 Node 进程  

2. **解压并覆盖线上数据库**（路径按你线上实际部署调整）  
   - 若线上项目在 `/app` 且数据目录为 `/app/server/data`：
   ```bash
   gunzip -c /tmp/lnexam-production.db.gz > /app/server/data/lnexam.db
   ```
   - 若用 Docker 且挂载的 volume 为 `./server/data`：
   ```bash
   gunzip -c /tmp/lnexam-production.db.gz > ./server/data/lnexam.db
   ```

3. **启动服务**  
   - Docker: `docker start <容器名>`  
   - systemd: `sudo systemctl start lnexam`  
   - 或 `cd server && node server.js`  

完成后线上即使用与本地相同的题库和解析。

---

## 四、以后更新题库/解析时

在本地重新跑一遍「一」生成新的 **lnexam-production.db.gz**，再按「二」「三」上传并覆盖、重启即可。
