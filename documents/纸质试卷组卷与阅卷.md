# 纸质试卷：组卷、打印、拍照与阅卷

## 功能说明

- **按考试形式组卷**：与「模拟考试」相同的 `exam_configs` 规则（含三科综合）。
- **按知识点组卷**：按科目选择多个知识点分类，并为每个分类指定抽题数量。
- 组卷后写入 `paper_sessions`，状态：`pending` → 上传图片后 `uploaded` → 提交答案阅卷后 `graded`。
- **打印试卷**：前端调用 `GET /api/users/me/paper-sessions/:id/sheet` 打开新窗口打印（题目不含正确答案）。打印页含 **考生信息栏、试题、答题卡**（题号与 A/B/C/D 填涂格，含 **试卷编号** 便于拍照后与会话关联，便于后续视觉识别）。
- **拍照上传**：`POST /api/users/me/paper-sessions/:id/uploads`，字段名 `photos`（多文件），存于 `server/data/uploads/paper/{userId}/{sessionId}/`（已加入 `.gitignore`）。
- **阅卷**：用户在「提交答案阅卷」中按在线考试方式点选选项，提交 `POST /api/users/me/paper-sessions/:id/grade`，服务端客观题比对标准答案，写入 `exam_records`、合并 `user_mistakes`，并返回完整错题 id 列表供前端同步。

## 阶跃星辰 AI 识别答题卡

- **推荐**：管理员登录 → **后台管理 → API 配置**，填写阶跃星辰 **API Key**（可选 Base URL、视觉模型），密钥写入数据库 `app_settings`。**保存后全体已登录学员均可使用「AI识别答题卡」**，共用该密钥与额度，学员无需也不应各自申请 Key。
- **或** 使用环境变量 **`STEPFUN_API_KEY`**（勿提交到 Git）。可选：`STEPFUN_API_BASE`、`STEPFUN_VISION_MODEL`。
- **优先级**：数据库中的配置 **优先于** 环境变量（便于在后台修改而无需改部署）。
- 接口：`POST /api/users/me/paper-sessions/:id/recognize`（需登录，且该卷已上传照片）。服务端读取已存图片调用视觉模型，返回 `{ answers: { [questionId]: 0|1|2|3 } }`。
- 前端「**AI识别答题卡**」会调用上述接口并进入答题页预填选项；**提交前务必人工核对**，再交卷阅卷。
- 探测是否已配置密钥：`GET /api/users/me/paper-ai/status` → `{ stepfunConfigured: true/false }`。

## 主要代码

- 库表：`server/db.js` → `paper_sessions`
- 组卷逻辑：`server/lib/paper-compose.js`
- 接口：`server/routes/paper-sessions.js` 通过 `registerPaperSessionRoutes` 注册到 `server/routes/users.js` 同一 Router（路径仍为 `/api/users/me/paper-sessions*`，需 JWT）
- 前端：`index.html` → 模拟考试页 `page-exams` 内「纸质试卷」卡片
